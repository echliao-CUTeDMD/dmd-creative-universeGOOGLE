# 中國科技大學 數位多媒體設計系｜3D 互動創客元宇宙

本專案為參考 **[中國科技大學數位多媒體設計系官方網站 (`https://dmd.cute.edu.tw/`)](https://dmd.cute.edu.tw/)** 所打造的獨立 3D 互動式系所導覽網站（Single-Page WebGL Application）。

## ✨ 功能特色

- **13 座雙校區 3D 專業實驗室與主題展館**：
  - **中央核心**：數媒創客元宇宙廣場
  - **台北萬芳校區**：傳賢樓 202 系辦公室、傳賢樓 707 動作擷取與數位視效實驗室（MotionAnalysis Raptor-H 光學動捕）、7.1.4 全景聲環繞錄音室（Dolby Atmos）、傳賢樓 503 數位多媒體創作實驗室、格致樓數位展演與圖書中心
  - **新竹湖口校區**：日新樓 408 系辦公室、日新樓 301 3D 虛實整合實驗室（OptiTrack）、日新樓 306 三維影音電腦動畫實驗室、啟我大樓多通道弧形投影廳
  - **專業主題館**：數位遊戲與電競創客館、國際紅點與動畫影展館、VTuber 虛擬網紅與 AI 創客館
- **四大核心課程領域**：數位遊戲設計、3D 電腦動畫與視效、XR 虛實整合與生成式 AI、數位音樂與全景聲成音
- **師資陣容 3D 駐點導覽、國際紅點獎與全國競賽榮譽榜、四年一貫專題製作地圖**
- **數媒創客護照（6 大互動問答闖關）** 與 **Web Audio 即時合成電音配樂**

## 🚀 部署至獨立 GitHub Repository 與 GitHub Pages

1. 在 GitHub 建立一個全新的獨立 Repository（例如 `cute-dmd-3d`）。
2. 將本資料夾內的 `index.html`、`README.md`、`.nojekyll` 直接上傳至該 Repository 根目錄。
3. 前往 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)` 並按 **Save**。
4. 發布完成後即可透過 `https://<您的帳號>.github.io/<倉庫名稱>/` 獨立瀏覽。
